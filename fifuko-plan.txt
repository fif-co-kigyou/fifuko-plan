フィフ子の起業計画メーカー
目標：個別サービス ／ 週2時間。無理のない範囲で進めよう。

第1週
[ ] 説明や手順を修正する
[ ] よくある質問をまとめる

第2週
[ ] noteやSNSで紹介する
[ ] 問い合わせ方法を明確にする

第3週
[ ] 受付を開始する
[ ] 最初の問い合わせを記録する

第4週
[ ] 反応と負担を振り返る
[ ] 次の改善を1つ決める

第5週
[ ] 商品説明を読み直す
[ ] 問い合わせしやすい導線を作る

第6週
[ ] 実際の利用者像を調べる
[ ] よくある悩みをまとめる

第7週
[ ] noteで役立つ記事を公開する
[ ] 記事から商品への導線を設ける

第8週
[ ] 紹介文の別案を作る
[ ] 小さく反応を比較する

第9週
[ ] 無料の見本を公開する
[ ] 見本から販売ページへ案内する

第10週
[ ] 閲覧や問い合わせを記録する
[ ] 反応がよい話題を探す

第11週
[ ] 商品の説明を改善する
[ ] 利用者の声があれば反映する

第12週
[ ] 発信を続ける仕組みを考える
[ ] 次の1か月の計画を作る
